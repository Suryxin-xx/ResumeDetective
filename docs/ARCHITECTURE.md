# v4 架构决策

## 运行形态

v4 首版采用“单个 Go 程序 + 本地网页”的形态：程序负责 SQLite、备份、文件访问和 API，网页资源编译后嵌入程序。默认固定监听 `127.0.0.1:8765`，端口可在设置或启动参数中修改。

暂不使用 Wails/Electron。当前工具主要在浏览器中使用，本地服务可以减少桌面 UI 与网页 UI 的重复维护，也避免捆绑完整 Chromium。后续仅为 Windows 增加托盘入口、静默自启动和退出控制。

## 边界

```text
浏览器工作台
    ↓ 本机 JSON API
Go 应用服务
    ├─ SQLite 数据与迁移
    ├─ 简历/附件受控访问
    ├─ 备份、导入导出
    └─ 可选 AI Provider
```

服务只监听回环地址，并校验 Host。网页不使用 CDN，不把密钥、简历或 JD 发送给第三方；只有用户主动执行 AI 功能时，才向用户配置的模型接口发送必要文本。

## UI 方向

产品定位是个人求职控制台，不是企业 ATS。视觉采用蓝灰底色、高密度表格和一条横向招聘阶段轨道。首页优先回答三个问题：哪些流程卡住、今天做什么、最近发生了什么变化。
