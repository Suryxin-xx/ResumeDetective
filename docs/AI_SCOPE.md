# AI 功能范围

v4 不内置通用聊天、Agent 工具调用或终端能力，只保留三类有明确输入输出的求职功能：

1. JD 与个人证据匹配：输出硬性要求、证据映射、缺口与投递建议。
2. 简历要点建议：基于用户确认的真实经历给出改写建议，不虚构数字和职责。
3. 面试准备/复盘提炼：生成针对性问题清单，或把复盘整理为薄弱项与行动任务。

Provider 使用 OpenAI 兼容的 `/chat/completions` 协议。DeepSeek 默认地址为 `https://api.deepseek.com`，模型名称不写死在数据库迁移中。密钥只保存在本地安全存储或用户指定环境变量，日志和错误信息不得包含密钥、Authorization 请求头或完整简历正文。

结构化结果采用 JSON mode 时，提示词必须明确要求 JSON；流式响应需要处理 SSE `[DONE]`、空闲超时、取消和可重试的响应头阶段错误。
