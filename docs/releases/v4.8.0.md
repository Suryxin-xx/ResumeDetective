# ResumeDetective v4.8.0

这一版重点解决不同求职阶段的数据整理与恢复：秋招、春招可以各用一个独立空间，并保留原投递记录与文件路径。

## 新增与改进

- 求职空间：创建、重命名、切换与可逆归档；不同空间独立保存投递、面试、Offer、资料库、简历、附件及 Excel。
- 完整空间备份：数据库一致性快照、简历、附件与文件校验清单打包为 `.space.zip`。恢复创建新副本，不覆盖现有记录；API 与软件设置仍共用，不包含在空间备份中。
- 安全切换：切换前备份并重启；旧网页停止读写，刷新后再使用。损坏或不兼容的目标不会静默覆盖原数据。
- 投递详情默认只读，编辑资料分组展示；未保存修改会提示，历史多轮面试按轮次展开。
- 设置分类切换保留输入；统一表单字号、圆角与文件选择控件，精修空间窗口、新建投递、流转时间线与提醒列表。
- 首页增加考虑中 Offer 的近期截止提醒；收入计算显示随输入更新的税前、到手、月均及公积金摘要，计税算法保持不变。

## 升级注意

1. 从旧版本升级前，请退出程序并完整复制原 `data` 目录作为备份；旧版本更新器可能仍只备份数据库。
2. 本版不改变数据库结构，仍使用 schema v13。原 data 作为默认空间，不会移走原投递、简历或 Excel。
3. 使用软件内更新，或退出旧程序后用新 EXE 替换原 EXE。不要用发布包的演示 `data` 覆盖你的个人数据。
4. 不要将旧版本程序与新空间目录混用。需要回退时使用升级前的完整目录副本。

## 下载

下载 `ResumeDetective-windows-x64.zip` 与同名 `.sha256`，核对 SHA-256 后完整解压。首次使用的包内数据全部虚构，可在总览清除演示数据。

软件仅监听本机 localhost，最终用户无需安装 Python、Go 或 Node.js。Windows EXE 未做商业代码签名，部分电脑可能显示未知发布者提示。

公开 Release 上传后，建议从旧版本进行一次在线检查、下载、校验与安装验证；本地回归不代替 GitHub 上线后的完整更新演练。
